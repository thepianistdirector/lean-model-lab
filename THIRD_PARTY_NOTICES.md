# Source, fixture and dependency provenance

This local development candidate contains Lean Model Lab Python source and its
AGPL-3.0-only license, plus a llama.cpp compiler compatibility patch carrying
the upstream MIT notice below. It bundles no Python interpreter, third-party Python
package, native backend, model weights, tokenizer file, font, browser script or
remote asset. The standalone report uses local HTML/CSS and system fonts.

The key-copy workload is generated by `src/lean_model_lab/contracts.py` from the
fixed seed and in-repository word list. Expected keys, request text, invalid
controls and evaluator fixtures are synthetic project material under the same
repository license. The model-free fixture report uses manufactured times and outputs;
neither a model nor a human participant supplied those fixtures. Separately
labeled measured reports contain actual model outputs from the admitted CPU run;
no human participant or independent external observer supplied that evidence. External research papers
and backend documentation are referenced, not redistributed as project source.

The control program uses the separately installed Python standard library.
The interpreter and host system libraries retain their own licenses and are
not included in the zipapp.

## Local browser validation dependencies

The offline 0.4 workbench uses system fonts and project-authored JavaScript. Browser validation uses separately cached Chromium executables and reviewed AlmaLinux 8 libraries extracted only into the project cache. The initial headless-shell check used three packages; the full Chromium zoom check acquired ten additional reviewed RPMs and staged only eight required libraries from seven of them. Exact package identities, applicable upstream notices, signature checks, selected extraction and sandbox observations are recorded in `docs/decisions/browser-validation-deps.md`. Browser binaries, RPMs and libraries are not shipped in the source or zipapp and are not runtime dependencies of the workbench HTML.
