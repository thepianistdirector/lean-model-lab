# Isolated browser verification for v1

The first actual v1 workbench was captured at native 100% zoom with Chrome 140.0.7339.186, the normal renderer sandbox, a private debugging pipe and no owned TCP listener. Its visual capture succeeded, but the audit retained `STOP_EXTERNAL_CONNECTION_EVENT`: NetLog contained a UDP connect event for an external IPv6 address. No UDP-bytes-sent or TCP-connect event was recorded. This is an observation from NetLog and process snapshots, not a packet-capture proof; the stopped receipt has not been relabeled as an unconditional pass.

The follow-up uses a new user/network namespace created only for the browser process. The launcher maps the actual nonzero user/group IDs to themselves, verifies that the network namespace changed, checks that only loopback exists and that no IPv4 route is present, then executes the reviewed browser. It does not change host interfaces, routes, firewall, accounts or persistent configuration. Chromium's own sandbox remains enabled. Linux documents the relationship between [user namespaces and namespace ownership](https://man7.org/linux/man-pages/man7/user_namespaces.7.html) and the resources isolated by [network namespaces](https://man7.org/linux/man-pages/man7/network_namespaces.7.html).

A standalone namespace probe passed with the expected nonzero identity, loopback-only device inventory and empty route table. The actual follow-up browser runs then passed at [100%](../evidence/v1-preliminary-browser-100.json) and [200%](../evidence/v1-preliminary-browser-200.json) native zoom, after queueing behind native research using the same project heavy-job lease. Both observed the retained namespace, normal sandbox flags, loopback only, no routes, no owned IP sockets or listeners, unchanged document bytes and complete process cleanup. The IPv6 route probe failed inside the isolated namespace. The root agent inspected both actual screenshots. This is process and browser instrumentation, not a packet capture or a human accessibility audit.

The audit distinguishes native browser zoom from CSS enlargement and device-scale emulation. The preliminary 200% run recorded browser zoom 2, CSS visual viewport width 712.5, and body/HTML CSS zoom 1. Keyboard operations, visible focus, narrow reflow and the final distribution remain explicit final-package checks. A same-host automated browser is not an independent accessibility reviewer or external participant.
