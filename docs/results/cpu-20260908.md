# CPU comparison — 8 September 2026

**Finding: INELIGIBLE for an efficiency claim.** All twelve real arm runs completed, but every arm answered only 99 of 128 requests exactly (77.34375%), below the frozen 95% gate. At concurrency 4, baseline/candidate output-token parity also failed in all three pairs. The quality rule, workload and thresholds were not relaxed after observing outputs.

This is a local measured result from the development package `0.1.0.dev0`, not a public release, external reproduction, or qualified human review. It establishes that this model/policy combination did not meet this synthetic task contract. It does not establish a statistically supported no-speedup result: comparable-quality efficiency was not available to estimate.
