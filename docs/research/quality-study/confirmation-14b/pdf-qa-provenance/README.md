# Optional PDF-QA dependency provenance

`pypdfium2==5.13.0` was newly installed into the investigator's project-local QA directory to rasterize generated PDFs. It was not preexisting, is not required by `portable_reanalysis.py`, and does not participate in model inference. The pinned optional requirement is [requirements-pdf-qa.txt](../requirements-pdf-qa.txt).

[provenance.json](provenance.json) retains the exact original install argv/log hash, available timing evidence, official wheel URL/SHA-256 and post-install verification. The original command did not request a pip resolver report; the later verification report is explicitly labeled rather than presented as an original report. Tool-reported wall time and filesystem log timestamps have different boundaries, and no exact original monotonic install interval was recorded. The common allocation clock still charges the work. The initial installer cache location, environment and complete filesystem footprint were not captured: a project-local `--target` directory does not establish a fully recorded installer footprint.

The exact 3,730,077-byte wheel has SHA-256 `81df25c1ab4c13ff773102d3cbea1967511d079123b067fc077bd0c4d57d91d8`, matching the [official release metadata](https://pypi.org/pypi/pypdfium2/5.13.0/json). All 71 wheel files other than the installer-rewritten RECORD matched installed bytes. A verification download retained the official wheel; there was no second installation. `installed-metadata/` includes the installed RECORD and metadata, and `license-files/` preserves all 19 license files identified in the wheel. Declared licensing is BSD-3-Clause, Apache-2.0 and bundled dependency licenses; these declarations are preserved rather than reduced to a single blanket license.

[The exact rendering receipt](../rendered-pdf-checks.json) identifies the reusable helper, argv, elapsed time and source/preview hashes. Its PDF rasterizations matched the previously visually inspected previews byte-for-byte. The helper uses `PdfDocument`, sequential `page.render(scale=1.8)` and `bitmap.to_pil().save(PNG)`, following the [primary API documentation](https://pypdfium2.readthedocs.io/en/stable/python_api.html). This is agent visual QA of generated research figures, not external human validation.

[The publication filename map](publication-filename-map.json) records all eight original names and their included `.txt` names with exact SHA-256 values and retained private-original locations. This includes [the original install log](original-install.log.txt), [installed METADATA](installed-metadata/METADATA.txt), [installed RECORD](installed-metadata/RECORD.txt), INSTALLER, REQUESTED, WHEEL and both copies of the IJG license. The added extension changes filenames only. Original installed-file paths remain authoritative in [the installed inventory](installed-file-inventory.json); its publication-copy fields identify the included files. No private installation evidence was renamed or removed.

[The publication encoding map](publication-encoding-map.json) identifies both `freetype.txt` copies, whose original Latin-1 bytes fail the source archive UTF-8 requirement. Their included UTF-8 derivatives preserve the decoded text; the map records original and derived lengths and SHA-256 values. For each included file, `included_bytes.decode('utf-8').encode('latin-1')` reproduces the exact retained original bytes; both roundtrips were verified. Installed-file and official-wheel inventory hashes still identify the original bytes, while publication-copy hashes identify the UTF-8 derivatives. All other license contents are included byte-for-byte.
